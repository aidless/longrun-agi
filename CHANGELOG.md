# Changelog

All notable changes are recorded here. This project uses semantic version tags.

## [0.1.0] - 2026-10-29

### Added

- CLEAR-300-v1 frozen CPU benchmark and deterministic model-evaluation protocol.
- P1-P8 synthetic and CPU probes, including persistent SQLite memory and real temporary filesystem/subprocess faults.
- Versioned evidence artifacts with provenance and SHA-256 verification.
- Strict claim schema, portfolio audit, model gate, public evidence dashboard, and open-source governance files.

### Evidence boundary

No model evaluation, external benchmark, GPU job, paid API call, novelty finding, production-readiness finding, or AGI claim is part of this release.
