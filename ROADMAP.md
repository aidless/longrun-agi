# Roadmap

The roadmap is ordered by evidence value, not feature count.

## R1 — Public reproducibility

- Keep CI, artifact hashes, and the evidence dashboard aligned.
- Add independent reproduction reports and platform compatibility evidence.
- Improve real-fault coverage without claiming production resilience.

## R2 — External protocols

- Specify adapters for LongMemEval/LoCoMo-style memory evaluation without selecting or downloading data.
- Define real tool/browser fault protocols with privacy and account boundaries.
- Obtain external review of CLEAR-300-v1 validity and leakage risks.

## R3 — Model-gated evaluation

- Complete `MODEL-GATE-APPLICATION.md` for one immutable open-weight artifact.
- Measure capacity on the exact approved cloud target.
- Run train/dev preflight first; keep the 60-task test split sealed until a separate go/no-go decision.

## Stop rules

Do not replace failed probes with stronger prose. Do not unlock model work merely to fill a roadmap item. External publication and resource use remain explicit decisions.
