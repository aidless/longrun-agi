# Literature Search: 2026-10-27

## Scope

Targeted search for prior work on:

- evolving rules and test-time adaptation;
- transient tool failures and recovery;
- memory poisoning, stale context, and provenance;
- failure attribution in long-horizon agents;
- factorized, counterfactual, or factorial benchmark designs.

The search was CPU-only and used the public arXiv export API. No model API,
paid service, or PDF corpus was used. Titles, identifiers, authors, dates, and
abstracts were verified against the API and stored in
`literature/arxiv_verified_20261027.json`. Full texts were not manually audited
in this pass; all entries are preprints unless later publication is separately
verified.

## Current novelty verdict

**Not established.** The verified literature already contains:

1. paired counterfactual/rollout designs;
2. controlled failure injection with golden labels;
3. step-level causal attribution and interaction credit;
4. separate benchmarks for rule drift, tool faults, and memory poisoning;
5. factorial experiments for agent components and model/format interactions.
6. combined stress benchmarks and a 24-configuration memory-security matrix.

The narrow remaining hypothesis is:

> A unified, model-free generator can create paired long-horizon tasks whose
> environmental factors are statistically crossed, and can recover known
> main effects and interactions with an auditable reference policy before any
> model is evaluated.

This is a measurement/harness contribution. Its value is not established until
it demonstrates a practically important interaction that existing benchmarks
cannot recover, or predicts model-agent failures prospectively. A 2x2
rule-shift x tool-fault demo alone is insufficient. The verified `2x2x2`
extension is still only a local control prototype: the tested scripted
policies produced no nonzero three-way interaction.
